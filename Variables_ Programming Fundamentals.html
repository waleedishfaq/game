What is a variable?

A variable is a named box that stores a value. The name is the label. The value is what's inside. You can look inside or swap the value any time.

let vs const

let makes a value you can change. const locks it. Use const for things that never change, like the max lives.

let lives = 3; const maxLives = 3;
